## 🌟 Featured Projects

### ✈️ [TravelNexus-AI](https://github.com/PiyushAgarwalcs/TravelNexus-AI)
**Multi-Agent AI Travel Planning System**

- Built a supervisor-based multi-agent architecture using LangGraph.
- Orchestrates specialized agents for flights, hotels, weather, budgets, and itineraries.
- Integrates external APIs through MCP and supports human approval workflows.
- Includes PostgreSQL checkpointing, automated tests, and LLM evaluation.

`Python` `LangGraph` `MCP` `FastAPI` `PostgreSQL`

### 🔎 [AI/ML Job Discovery Pipeline](https://github.com/PiyushAgarwalcs/aiml_jobalert_bypa)
**Automated Job Discovery & Notification System**

- Collects job listings from 300+ career portals and 15+ ATS providers.
- Uses asynchronous processing, deduplication, and automated job alerts.
- Implements retries, timeout handling, and scheduled GitHub Actions workflows.

`Python` `asyncio` `aiohttp` `SQLite` `GitHub Actions`

### 🛡️ [ITAS](https://github.com/PiyushAgarwalcs/ITAS)
**Intelligent Threat Assessment System**

- Explores computer vision for object detection, face recognition, and video analysis.
- Combines multiple vision models in an integrated application.
- Includes a Streamlit dashboard for presenting AI-driven outputs.

`Python` `YOLO` `OpenCV` `Deep Learning` `Streamlit`

### 📈 [Stock Price Prediction](https://github.com/PiyushAgarwalcs/Indian_Stock_Price_Prediction)
